# Student Python Demo

A tiny repository for demonstrating GitHub import/clone and Python execution in Mirage IDE.

## Files

- `hello.py` — prints a simple greeting.
- `student_details.py` — asks for a student's name and class, then prints the entered details.

## Run locally

Make sure Python 3 is installed.

```bash
python hello.py
python student_details.py
```

On some systems, use `python3` instead of `python`.

## Demo plan in Mirage IDE

1. Import or clone this repository using its public GitHub HTTPS URL.
2. Open `hello.py` and click **Run**. Expected output includes `Hello from Mirage IDE!`.
3. Open `student_details.py` and click **Run**.
4. Enter a sample name such as `Aarav` and class such as `FY BSc`; show the printed details.

## Example output

For `hello.py`:

```text
Hello from Mirage IDE!
My first Python program is running successfully.
```

For `student_details.py`:

```text
Enter the student's name: Aarav
Enter the student's class: FY BSc

--- Student Details ---
Name : Aarav
Class: FY BSc
```
